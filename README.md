# Skill: Analisa Mercado Financeiro

Plugin para [Claude Code](https://docs.claude.com/claude-code) — parte do ecossistema [LSC-Lab](https://lsc-lab.com).

## Instalação

```bash
# Clone para o diretório de skills do Claude Code
mkdir -p ~/.claude/skills
git clone https://github.com/lscecilio/skill-analisa-mercado-financeiro.git ~/.claude/skills/analisa-mercado-financeiro
```

Ou no escopo do projeto:

```bash
mkdir -p .claude/skills
git clone https://github.com/lscecilio/skill-analisa-mercado-financeiro.git .claude/skills/analisa-mercado-financeiro
```

## O que faz

Veja [`SKILL.md`](./SKILL.md) — frontmatter `description` define quando o Claude Code ativa esta skill automaticamente.
